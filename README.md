# Atelier Nord: The Turnwell

Two versions of a scroll-driven WebGL portfolio hero (three.js):

- `index.html`: ring tunnel. Dive down a well of website cards to the man on the lit floor, then the room.
- `index-wall.html`: curved wall. Walk along a half-cylinder of cards that curves round the room, same ending.

Fonts: Bodoni Moda and Jost (SIL Open Font License), self-hosted in `assets/fonts`.
